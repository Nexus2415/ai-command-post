# ARN-169: Brain private document deliverables

Source-only first milestone. The existing ChatGPT worker tool dispatch can create a real deterministic DOCX via an explicitly injected synthetic capability. It accepts only structured title/headings/paragraphs, a simple .docx filename, and bounded content. No macros, external links, filesystem destination, model-visible file bytes or new dependency. Missing scope or dry-run refuses. The fixture writes a private file to an isolated temporary directory and independently opens the actual ZIP and XML with Python 3; it tests exact replay, altered content, cross-principal, expiry, stop and private-thread revocation. Python 3 is required for the independent document-format test (available on the existing Ubuntu CI runner).

The fixture is not production authority or durable workspace storage. Next: actual scoped owner-private artifact storage and retrieval with atomic stop/expiry/fence/lineage enforcement, and a full scripted goal through document creation and independent verification. No runtime adapter, provider request, new permissions, or production schema change. PDF, spreadsheets and slides remain unsupported. Do not claim full ARN-169 readiness until these requirements and independent review are satisfied.
